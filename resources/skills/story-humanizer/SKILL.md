# Story Humanizer

帮助复核和编辑中文网络小说，让正文整体更像自然说话，更适合用户用嘴读出来或连续听下去，同时保护作者声音、剧情事实与题材质感。这里的“口语化”包含叙述，不只是对白：词要常用，句子要好念，连接要松一点，允许自然重复、补说、停顿和不完全工整的句子。可以有口语里的小毛边，但不要靠错别字、错误人名数字、事实错误或严重语病制造“人味”。

## 本技能管什么

- 网络小说的口语化听读复核与编辑（叙述和对白一起改）。
- 网文专项的模板化句式、表情套路、书面腔降频与听读节奏。
- 以 5 篇内置人类样文为师，模仿其听读节拍，不逐词复制。

## 通用规则交给 human-writing

- 成稿硬禁令（翻案句、黑话、破折号、冒号、排比、名词化、模型路标、抒情词）与 check_prose 工具用法，见 human-writing 技能的“成稿绝对不能出现”与 references/revision.md。
- 材料检查、人物/场景/对白/结尾等通用虚构写法，见 human-writing references/fiction.md。
- 通用七遍改稿（保真、表演性中文、词序、清禁用项、核设定、结尾），见 human-writing references/revision.md。
- 编辑工具用法（edit.lineEdits/paragraphEdits/expectedSourceHash）见项目工具说明。

## 完整流程

1. **阅读目标确认**：默认启用“口语化听读模式”。先确认题材、时代、叙述视角和用户要保留的语气；“口语化”不等于把所有句子砍短，也不等于把古风、惊悚、史实术语全部换成现代俚语。
2. **自动检查**：读 references/01-检测评分.md，调用 check_prose({ path: "chapters/{id}" })（临时正文用 content）过一遍硬禁令；同时人工留意复杂从句、四字格堆叠和朗读时容易卡住的位置。
3. **作者基线**：有用户认可的同作者章节时，手动比较其句长、段落、连词与重复习惯（见 references/01-检测评分.md 与 references/07-人类文风基准.md）；5 篇内置样文只作参考基准，不是所有题材的通用标准。
4. **口语化编辑**：读 references/03-修改手册.md，按网文口语化专项操作（常用词替代、抽象名词还原、自然连接、叙述改对白）；优先用 read({ path, startLine, endLine }) + edit({ path, lineEdits|paragraphEdits }) 局部修改。
5. **问题诊断**：读 references/02-问题诊断与定位.md，按网文口语化诊断分层（口语与听读、声音、节奏、重复）定位分段处理范围。
6. **保真复核**：修改前保留正文快照，修改后人工检查数字、人物/地点/专名、对白数量和事实约束；语义判断不能交给工具。
7. **验收**：读 references/04-交稿验收.md，修改后再次调用 check_prose 直到硬性违规清零；口语化与听读流畅度、重复模式、保真分别报告。
8. **参考**：
   - 网文句式与口语复核表：references/05-禁词与句式表.md
   - 改写范例库：references/06-改写范例库.md
   - 人类文风基准：references/07-人类文风基准.md
   - 内置样文：references/human-style-samples/
   - 用户说“像样文/网站文风”时，至少读取一篇同题材或语气接近的样文，观察它怎样用常用词、弱连接、重复、停顿和长短句推进，不要只照搬样文里的词。

## 核心规则速记

- 网络小说的叙述也要有说话人的口气：可以用“结果、这下、其实、反正、没想到、也就、还、才”等弱连接，也可以补一句、绕一下、重复一下重点，让听者跟得上。不要只给对白降书面腔。
- 听读优先于书面漂亮：优先使用常用词和动词，减少多层定语、抽象名词、连续四字格、文言连接词和一口气读不完的套句；题材必要的专名、时代词和少量风格性词语可以保留。
- 人味来自具体观察、角色立场、语句的自然取舍、口语节拍和场景中的不对称反应。自然冗余、补说、半句停住、自己改口、成分省略和少量搭配松动可以保留，必要时可以有意放入一两处不影响理解的口语小错；不要刻意制造错别字、事实错误或读者需要回读的严重歧义。
- 不设置“一级禁词”：单个词（包括仿佛、突然、微微等）的自然出现不扣分；只在重复、固定搭配密集或上下文空泛时复核。破折号也是可选风格项，不自动判错。
- 不强制每段句数，不强制动作+对话+情绪循环。场景需要安静叙述、回忆、景物或内心时，可以完整保留这些形式。
- 不强制每 300-500 字加入对白；对白只有在能改变信息、目标、关系或权力时才值得加入。
- 优先保留作者已有的口头禅、句法习惯和题材词汇，修改目标是减少无意重复，不是把所有人写成同一种“人味”。
- 系统文里【】面板不因格式扣分；是否转述成对话或信物，取决于信息密度、阅读节奏和题材惯例。
- 统计、诊断、修改分阶段执行；检查工具返回结果后直接进入定位和局部修改，不重复抄写全文或在思考中生成完整草稿。

## 输出

改好的正文文件 + 复核报告（硬性违规 / 口语化与听读检查 / 重复与节奏风险 / 作者基线偏离 / 保真检查 / 修改意见 / 人工判断）。
