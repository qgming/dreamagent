# Story Humanizer

帮助复核和局部编辑中文网文章节，减少无意的模板化、重复和节奏僵硬，同时保护作者声音、剧情事实与可读性。第三方 AIGC 检测器只能作为外部反馈，不能承诺目标分数，也不能把检测结果当作作者身份判断。

## 完整流程

```
统计工具(01) → 作者基线比较 → 诊断(02) → 局部修改(03) → 保真复核 → 验收(04) → 参考(05/06/07)
```

1. **统计与定位**：优先调用 `text_stats({ path: "chapters/{id}", profile: "story-humanizer", dialogueExpectation: "none" })`；临时正文使用 `content`。需要核查某个词时显式传入 `terms`。关注工具返回的分布、重复模式、分段变化和定位，不手工数全文指标，不在统计阶段起草完整改写稿。
2. **作者基线**：有用户认可的同作者章节时，用 `referencePaths` 或 `referenceContents` 比较；公共 5 篇样文只作回归基准，不是所有题材的通用标准。
3. **检测与评分**：读 `references/01-检测评分.md`，输出结构风险、重复风险、作者基线偏离和需人工判断项。`structureScore` 只代表规则命中，不代表 AIGC 概率或作者身份。
4. **问题诊断**：读 `references/02-问题诊断与定位.md`，按空泛、声音、氛围、节奏、重复、语义漂移分层，确定最小修改范围。
5. **局部修改**：读 `references/03-修改手册.md`，按 保真→场景→段落→句子→节奏→词语 操作；优先用 `read({ path, startLine, endLine })` 或统计结果中的上下文，再用 `edit({ path, lineEdits })` / `edit({ path, paragraphEdits })`。每次修改必须提供 `expectedText`；有统计结果时同时提供 `expectedSourceHash`。
6. **保真复核**：修改前保留正文快照，修改后调用 `text_compare({ before, after, terms })`，检查数字、人物/地点/专名、对白数量和事实约束。工具只能提示，语义仍需人工确认。
7. **验收**：读 `references/04-交稿验收.md`，修改后再次调用 `text_stats`；结构分、重复模式、基线偏离和语义保真分别报告。
8. **参考**：
   - 禁词与句式表：`references/05-禁词与句式表.md`
   - 改写范例库：`references/06-改写范例库.md`
   - 人类文风基准：`references/07-人类文风基准.md`
   - 内置样文：`references/human-style-samples/`

## 核心规则速记

- 句末密度先看作者自己的可比章节；没有基线时才把 5 篇内置样文作为宽松参考，超出范围只提示局部复核，不为追区间机械合并或拆句。
- "的"密度、逗号密度和句长分布只作描述项，不为凑数字堆修饰语。
- 段落数、短段占比和超过 60 字的长段都只是分布信号；先看是否混入多个叙事功能，再决定拆分、合并或保留。
- 对话要求按章节功能设置：`dialogueExpectation="none"` 表示本章不要求对话；`"some"` 只要求出现有叙事作用的对话；`"driving"` 才在明显偏低时提示复核。任何占比都不是所有章节的硬指标。
- 不强制每段句数，不强制动作+对话+情绪循环。场景需要安静叙述、回忆、景物或内心时，可以完整保留这些形式。
- 不设置“连续多少字不得复用”的通用禁令。专名、术语、固定称呼和有意回环可以保留；只处理无意的整句或固定搭配重复。
- 人味来自具体观察、角色立场、语句的自然取舍和场景中的不对称反应，不等于刻意制造错别字、碎句或“毛边”。
- 不设置“一级禁词”：单个词（包括仿佛、突然、微微等）的自然出现不扣分；只在重复、固定搭配密集或上下文空泛时复核。破折号也是可选风格项，不自动判错。
- 重点复核固定句式密集、解释堆叠和章末总结升华；【】系统面板在系统文中可以合法存在，不因格式本身判错。
- 不强制每 300-500 字加入对白；对白只有在能改变信息、目标、关系或权力时才值得加入。
- 优先保留作者已有的口头禅、句法习惯和题材词汇，修改目标是减少无意重复，不是把所有人写成同一种“人味”。
- 系统文里【】面板不因格式扣分；是否转述成对话或信物，取决于信息密度、阅读节奏和题材惯例。
- 金手指、首用失败、弱钩子等属于题材/章节目标检查，不作为所有文章的通用规则。
- 统计、诊断、修改分阶段执行；统计工具返回结果后直接进入定位和局部修改，不重复抄写全文或在思考中生成完整草稿。

## 输出

改好的正文文件 + 复核报告（结构指标 / 重复与节奏风险 / 作者基线偏离 / 保真检查 / 修改意见 / 达标项 / 人工判断）。
