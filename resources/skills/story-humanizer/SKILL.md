# Story Humanizer

把中文网文章节改写为「人工特征」风格，让 AIGC 检测值降到 0.5 以下。

## 完整流程

```
统计工具(01) → 诊断(02) → 局部修改(03) → 验收(04) → 参考(05/06/07)
```

1. **统计与定位**：对已有文章优先调用 `text_stats({ path: "chapters/{id}", profile: "story-humanizer", dialogueExpectation: "none" })`；临时正文使用 `content`。需要核查某个词时显式传入 `terms`。不要手工数全文指标，不要在统计阶段起草改写稿。
2. **检测与评分**：读 `references/01-检测评分.md`，使用工具返回的全文指标、逐项命中、分段风险定位，输出规则风险报告。AIGC 区间只能作为经验参考，不得表述为真实检测值。
3. **问题诊断**：读 `references/02-问题诊断与定位.md`，按分层（空泛/声音/氛围/节奏）和症状反查根因，确定改哪层。
4. **局部修改**：读 `references/03-修改手册.md`，按 结构→段落→句级→节奏→词级 五层操作；优先用 `read({ path, startLine, endLine })` 或统计结果中的上下文读取高危区，再用 `edit({ path, lineEdits })` / `edit({ path, paragraphEdits })` 修改。每个修改必须提供 `expectedText`；有统计结果时同时提供 `expectedSourceHash`。开始改稿前先读 5 篇样文（`references/human-style-samples/`）建立语感。
5. **验收**：读 `references/04-交稿验收.md`，修改后再次调用 `text_stats` 复查，再做五维打分（<35/50 再改一轮）。
6. **参考**：
   - 禁词与句式表：`references/05-禁词与句式表.md`
   - 改写范例库：`references/06-改写范例库.md`
   - 人类文风基准：`references/07-人类文风基准.md`
   - 0% 样文：`references/human-style-samples/`

## 核心规则速记

- 句末密度以 5 篇内置人类样文为基准，参考范围约 23-50/千字，20-55 之外才提示复核；不要为了追区间机械合并或拆句。
- "的"修饰语 ≥20/千字（洗得发白的军裤 / 灰毛衣的毛边）。
- 段落数 95-118、短段（≤20 字）约 19-54% 仅作参考；>60 字超长段允许与样文相近，数量和占比都明显超出后才提示。
- 对话要求按章节类型设置：`dialogueExpectation="none"` 表示本章不要求对话；`"some"` 只要求确实出现有效对话；`"driving"` 才在低于 10% 时提示复核。25-40% 仅是对话驱动章节的参考区间，不是所有章节的硬指标。
- 段落不超 3 句；动作+对话+情绪反应三要素循环；情绪用动作/物件外化，不贴标签。
- 连续 12 字以上的原句不许复用，改写必须换句式。
- 人味 = 刻意不完美：长短错落、口语毛边、半句留白、具体到不像编的细节。
- 不设置“一级禁词”：单个词（包括仿佛、突然、微微等）的自然出现不扣分；只在重复、固定搭配密集或上下文空泛时复核。破折号也是可选风格项，不自动判错。
- 重点避免固定句式密集、【】系统面板堆叠和章末总结升华。
- 系统文里【】面板不扣分，但越少越好，优先转述成对话/信物。
- 金手指首用必须带失败/代价/反高潮；结尾用弱钩子，不喊口号。
- 统计、诊断、修改分阶段执行；统计工具返回结果后直接进入定位和局部修改，不重复抄写全文或在思考中生成完整草稿。

## 输出

改好的正文文件 + 检测报告（得分 / 预测 AIGC 区间 / 高危片段 / 修改意见 / 达标项 / 五维打分）。
