# Story Humanizer

把中文网文章节改写为「人工特征」风格，让 AIGC 检测值降到 0.5 以下。

## 完整流程

```
检测(01) → 诊断(02) → 修改(03) → 验收(04) → 参考(05/06/07)
```

1. **检测与评分**：读 `references/01-检测评分.md`，统计全文指标、逐项扣分、切段定位高危区、输出预测报告。
2. **问题诊断**：读 `references/02-问题诊断与定位.md`，按分层（空泛/声音/氛围/节奏）和症状反查根因，确定改哪层。
3. **修改**：读 `references/03-修改手册.md`，按 结构→段落→句级→节奏→词级 五层操作；先改红区段（叙述→对话）。开始改稿前先读 5 篇样文（`references/human-style-samples/`）建立语感。
4. **验收**：读 `references/04-交稿验收.md`，先跑 01 复查得分，再做五维打分（<35/50 再改一轮）。
5. **参考**：
   - 禁词与句式表：`references/05-禁词与句式表.md`
   - 改写范例库：`references/06-改写范例库.md`
   - 人类文风基准：`references/07-人类文风基准.md`
   - 0% 样文：`references/human-style-samples/`

## 核心规则速记

- 句号密度 35-40/千字，>45 扣分；用逗号串长句，句号留给段落收尾。
- "的"修饰语 ≥20/千字（洗得发白的军裤 / 灰毛衣的毛边）。
- 段落数 95-118，短段（≤20 字）≥20%，无 >60 字长段。
- 对话占比 25-40%；连续 3 句无引号即高危；独白叙述是红区主源，改成人物一来一回。
- 段落不超 3 句；动作+对话+情绪反应三要素循环；情绪用动作/物件外化，不贴标签。
- 连续 12 字以上的原句不许复用，改写必须换句式。
- 人味 = 刻意不完美：长短错落、口语毛边、半句留白、具体到不像编的细节。
- 禁止：破折号、情绪套话（心里咯噔一下等）、AI 高频词组合（然而/仿佛/这一刻）、【】系统面板堆叠、章末总结升华。
- 系统文里【】面板不扣分，但越少越好，优先转述成对话/信物。
- 金手指首用必须带失败/代价/反高潮；结尾用弱钩子，不喊口号。

## 输出

改好的正文文件 + 检测报告（得分 / 预测 AIGC 区间 / 高危片段 / 修改意见 / 达标项 / 五维打分）。
