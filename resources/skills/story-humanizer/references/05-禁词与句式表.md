# 05 词语与句式复核表

> 不再设置“一级禁词”。自然词语不能单独证明文章像 AI，单次出现也不应被自动替换。只有重复、固定搭配密集、语义空泛或与上下文不匹配时，才进入局部复核。

## 词语判断原则

- `仿佛`、`好像`、`突然`、`瞬间`、`微微`、`缓缓`、`淡淡` 等都是正常中文词语，不因出现一次就扣分。
- 先看频率，再看位置：同一词在短距离内反复出现，或每段都用同一种情绪模板，才值得改。
- 再看语义：如果词语后面没有具体动作、物件或结果，只是在替作者宣布情绪，优先改成可观察的细节。
- 工具不会自动把这些词加入结果。需要核查时显式传入 `terms`，利用行号、段号和上下文定位。

## 需要人工复核的信号

### 重复

- 同一词在相邻 2-3 段内反复出现。
- 同一类修饰语连续铺开，删掉后信息没有损失。
- 多个段落都使用“动作 + 一丝/一抹/几分 + 情绪名词”的同构表达。

### 固定句式

- “他/她终于明白……”
- “他/她这才意识到……”
- “此刻，他/她……”
- “一切……都……”
- “原来……”
- 连续 3 句相同结构排比。
- “有的……有的……有的……”或“一边……一边……一边……”。

这些句式也不是出现即删。先确认它们是否在同一段承担重复的总结功能，再保留最有力的一处或改成动作、对话和留白。

## 高风险表达模板

| 句式 | 示例 | 复核方向 |
|------|------|------|
| “……，带着……” | “他说，带着无奈” | 让动作或语气承担信息 |
| “像 XX 一样” | “像刀子一样锋利” | 换成具体对象和反应 |
| “他的声音很轻，却像……” | 过度文艺的声音比喻 | 保留可听见的语气变化 |
| “仿佛能……一般” | “仿佛能穿透一切一般” | 删除空泛能力判断 |
| “XX 说道” | “好的，他说道” | 用动作或直接对话收尾 |
| “他/她感到……” | “她感到失落” | 改为外化动作或物件 |
| “他/她意识到……” | “他意识到事情不对” | 让读者从反应中推断 |
| “眼中闪过一丝 XX” | “眼中闪过一丝悲伤” | 具体化眼神、停顿或动作 |
| “嘴角勾起一抹 XX” | “嘴角勾起一抹冷笑” | 避免万能表情模板 |
| “心中涌起一股 XX” | “心中涌起一股暖流” | 用身体反应或行为替代 |

## 通用书面腔

首先/其次/再次/最后/综上所述/总而言之/总的来说、值得注意的是/不难发现/由此可见/换句话说，以及没有明确立场的“一方面……另一方面……”，在网文正文中出现密集时应复核。

## 替换策略速查

| 原文类型 | 替换方法 | 示例 |
|----------|----------|------|
| 抽象情绪词 | 具体动作 | “紧张” → “手在抖” |
| “感到 XX” | 外化表现 | “感到愤怒” → “攥紧拳头” |
| 形容词堆砌 | 白描 | “美丽动人的笑容” → “她笑了” |
| 书面表达 | 口语化 | “不容置疑” → “就是” |
| 解释性描写 | 留白 | “他因为害怕而……” → “他退后一步” |
| 连续排比 | 保留最强一条 | 3 句排比留 1 句 |
| 总结升华句 | 删除或落到动作 | “这一刻，她终于明白……” → “她把门关上” |
