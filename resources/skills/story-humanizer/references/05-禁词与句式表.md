# 05 网文句式与口语复核表

> 不设置“一级禁词”，但用户要求网络小说整体口语化时，要主动复核过密的书面腔和模板化句式。自然词语不能单独证明文章像 AI，单次出现也不应被自动替换。只有重复、固定搭配密集、语义空泛、朗读卡顿或与上下文不匹配时，才进入局部复核。硬黑话、翻案句等绝对禁词见 human-writing 技能与 check_prose 工具。

## 词语判断原则

- 仿佛、好像、突然、瞬间、微微、缓缓、淡淡 等都是正常中文词语，不因出现一次就扣分。
- 先看频率，再看位置：同一词在短距离内反复出现，或每段都用同一种情绪模板，才值得改。
- 再看语义：如果词语后面没有具体动作、物件或结果，只是在替作者宣布情绪，优先改成可观察的细节。

## 口语化总原则

网络小说的叙述也要像人在讲故事。优先使用常用词、动词和弱连接，让句子好念、好听、能跟上。不要把口语化理解成满篇俚语、热梗、错别字或每句话都短；题材词、时代词、专业词和少量有风格的书面词可以保留。

所谓“故意犯错”，优先使用口语里的不完整、不对称、重复、补说和搭配松动：比如“他想了半天，没想出个所以然来”“这事吧，说起来也简单”“不是他不想，是他真没办法”。不要故意改错人名、数字、事实、知识，也不要制造听者无法判断意思的病句。

## 需要人工复核的信号

### 重复

- 同一词在相邻 2-3 段内反复出现。
- 同一类修饰语连续铺开，删掉后信息没有损失。
- 多个段落都使用“动作 + 一丝/一抹/几分 + 情绪名词”的同构表达。

### 固定句式

- “他/她终于明白……”
- “他/她这才意识到……”
- “此刻，他/她……”
- “一切……都……”
- “原来……”
- 连续 3 句相同结构排比。
- “有的……有的……有的……”或“一边……一边……一边……”。

这些句式也不是出现即删。先确认它们是否在同一段承担重复的总结功能，再保留最有力的一处或改成动作、对话和留白。

## 网文表情/万能句式模板

| 句式 | 示例 | 复核方向 |
|------|------|------|
| “……，带着……” | “他说，带着无奈” | 让动作或语气承担信息 |
| “像 XX 一样” | “像刀子一样锋利” | 换成具体对象和反应 |
| “他的声音很轻，却像……” | 过度文艺的声音比喻 | 保留可听见的语气变化 |
| “仿佛能……一般” | “仿佛能穿透一切一般” | 删除空泛能力判断 |
| “XX 说道” | “好的，他说道” | 用动作或直接对话收尾 |
| “他/她感到……” | “她感到失落” | 改为外化动作或物件 |
| “他/她意识到……” | “他意识到事情不对” | 让读者从反应中推断 |
| “眼中闪过一丝 XX” | “眼中闪过一丝悲伤” | 具体化眼神、停顿或动作 |
| “嘴角勾起一抹 XX” | “嘴角勾起一抹冷笑” | 避免万能表情模板 |
| “心中涌起一股 XX” | “心中涌起一股暖流” | 用身体反应或行为替代 |

## 高频时书面腔（不是硬禁）

首先/其次/再次/最后/综上所述/总而言之/总的来说、值得注意的是/不难发现/由此可见/换句话说，以及没有明确立场的“一方面……另一方面……”，在网文正文中出现密集时应复核。除此之外，下面这些词在用户要口语化时也要看密度和上下文：

| 书面偏重的表达 | 常见口语方向 | 备注 |
|---|---|---|
| 随后、继而、旋即、顷刻间、须臾 | 接着、然后、没一会儿、一下子 | 古风、史实或刻意的叙述腔可保留 |
| 闻言、见状、当即、遂、皆、亦 | 听到这话、看到这一幕、立刻、就、都、也 | 不要把古代人物的全部语言抹成现代口吻 |
| 进行观察、展开调查、作出决定 | 看了看、查一查、决定了 | 能直接说动作时优先直接说 |
| 处于等待状态、陷入沉思、产生恐惧 | 等着、想了半天、吓了一跳 | 抽象名词能换成动作时再换 |
| 由此可见、这说明、不可否认 | 所以、这就说明、确实 | 只在上下文真的需要解释时保留 |
| 不禁、未免、颇为、尤为、颇有 | 忍不住、多少有点、挺、特别 | 单次自然出现不必替换 |

这些是“降频参考”，不是同义词替换表。改完要重新读上下文，不能把每个“随后”机械换成“接着”。

## 可借用的口语连接

“就、也、还、又、才、倒是、结果、这下、其实、反正、没想到、哪知道、得了、行了、好家伙”等词可以让叙述松下来。它们需要符合叙述者和人物的身份，不要每段固定塞一个。尤其要保留样文里那种“先说完，再补一句”“事情看着顺，至少现在还顺”的自然回声。

## 口语化句式

- “不是……，是……”：自我修正或强调。
- “本来……，结果……”：把预期和现场结果接起来。
- “他想了想。其实也没想多久。”：留下一个停顿和轻微补说。
- “这下麻烦了。”、“跑不动了。”、“不是梦。”：用短句落地，不强行解释。
- “说起来简单，真做起来……”：允许一句话悬住，后面接动作或结果。
- “他也不知道自己在等什么，反正就是没走。”：用松一点的逻辑表现人物状态。

## 替换策略速查

| 原文类型 | 替换方法 | 示例 |
|----------|----------|------|
| 抽象情绪词 | 具体动作 | “紧张” → “手在抖” |
| “感到 XX” | 外化表现 | “感到愤怒” → “攥紧拳头” |
| 形容词堆砌 | 白描 | “美丽动人的笑容” → “她笑了” |
| 书面表达 | 口语化 | “不容置疑” → “就是” |
| 解释性描写 | 留白 | “他因为害怕而……” → “他退后一步” |
| 连续排比 | 保留最强一条 | 3 句排比留 1 句 |
| 总结升华句 | 删除或落到动作 | “这一刻，她终于明白……” → “她把门关上” |
