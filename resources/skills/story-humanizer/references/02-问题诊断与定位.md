# 02 问题诊断与定位

> 检测出分数后，用本文件定位"问题出在哪一层"。按症状反查原因，再进 03 修改手册找具体改法。

## 分层诊断

| 层 | 症状 | 根源 | 严重度 |
|----|------|------|--------|
| 1 空泛 | 总结句、情绪标签、告诉而非展示 | 用形容词代替动作细节 | 中 |
| 2 声音 | 人人一口，声线不分 | 没按角色拉开语言 | 中 |
| 3 氛围套话 | 空气凝固、仿佛、一丝 | 情绪套话+万能状语 | 高 |
| 4 节奏 | 句长齐、段齐、钟摆 | 均匀度太高 | 高 |

从大到小诊断：先看结构（层4），再看句子（层1/3），最后看人物（层2）。

## 症状 → 根因对照表

| 症状 | 根因 | 修改入口 |
|------|------|---------|
| AIGC 高危段集中在叙述/景物 | 独白式叙述过多，对话缺失 | 03·段落层（叙述→对话） |
| 整篇疑似但无红段 | 语料套路太常见（标准五段式/说明书对白） | 03·结构层 |
| 片段1红、片段2绿 | 前半是铺陈独白后半是对话 | 把独白段改成对话冲突 |
| 句号密度超标 | 碎句化：一句一段 | 03·句级（合并逗号流水句） |
| "的"密度过低 | 太干净无修饰 | 03·句级（补修饰语） |
| 有面板/客服/说明书 | 系统金手指处理不当 | 03·结构层（系统转信物） |
| 节奏均匀像节拍器 | 句长方差小、段长一致 | 03·节奏层（打碎） |
| 章末升华/预告 | 爱总结爱抒情 | 03·节奏层（砍总结句） |

## 负面特征全清单（命中即停写、回炉）

### 系统 / 金手指（红区主源）
- 堆叠【】面板把宿主/等级/次数/人望一屏列全 → 面板单处≤3行并转述成对话；能用纯对话/信物就替换。
- 系统像客服自我介绍（工号/规则/语气）→ 系统不现身、不解释、不承诺，只留模糊信号。
- 一段把规则全列完（每天一次/不可指定/作废/人望）→ 规则散进角色对话的只言片语。
- 金手指首用就成功且爽（打脸/认同/数值涨）→ 首用必须带失败/代价/反高潮。

### 结构与叙事骨架
- 标准五段式：绑定→质疑→试用→打脸→悬念 → 打乱顺序，加失败/反高潮。
- 全篇主角+工具人无配角 → 至少2个配角带生活细节（标签没剪的风衣/纠结饮水机的水）。
- 对话行占比 <18% → 提到≥25%，配合角色噪音与作者态度。
- 开场3行"几点钟+XX层+灯亮着" → 改物件/动作/一句怪话/回忆切入。

### 句级与词级
- 情绪套话（心里咯噔一下/后背凉了半截/眼珠子转得飞快/嘴角压不住/眼睛瞬间亮了/倒吸一口凉气/瞳孔猛缩/心提到了嗓子眼）→ 动作载体：手收紧/杯子没盖/眉头皱一下。
- AI 高频词组合（然而/因此/与此同时/总而言之/某种程度上/仿佛/犹如/宛如/这一刻/那一瞬间/时间仿佛）→ 单个可容忍，组合≥3必须替换为朴素动词+具体细节。
- 对称排比三连（他擦；他顶；他道谢）≥2次 → 打破对称。
- 破折号 → 全部换逗号/句号/分句。

### 宏观指标（参考）
- 段落数 <70 或 >130 → 复核。
- 同一主语连续开头（每几段就"沈默/他"起头）→ 打散为时间/动作/物件/他人名开头。
- 字数 <1800 → 容易"没展开"。

## 关键结论（历轮实测）

- 对话交互段 AIGC 0.40-0.43（人工区）｜独白叙述段 AIGC 0.79-0.99（AI区）——**同一篇判若两文**。
- 剧情/题材/金手指处理方式不是 AIGC 的决定因素，差异全在语言层。
- 优化重点 = 把叙述段对话化 + 调语言指纹，不是换剧情。
