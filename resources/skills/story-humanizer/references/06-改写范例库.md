# 06 网文口语化改写范例库

> 改稿时对照的范例。左边是常见的模板化写法，右边是一种更具体的写法；示例用于理解取舍，不是逐句替换规则。

## 叙述口语化对照

口语化不只发生在对白里。旁白也可以有一个人在讲故事的口气，允许顺手补一句、重复一下重点，或者说到一半停住。下面的右栏保留了叙事信息，只把书面阻力放低。

| 偏书面、偏摘要 | 口语化听读写法 |
|---|---|
| 他在短暂思考之后，决定立即离开此处。 | 他想了想，还是走吧。现在就走。 |
| 由于天气恶劣，赶路的计划被迫中止。 | 天气太差，路也没法走了。计划？先放一边。 |
| 她意识到对方并未说出全部真相。 | 她听完就知道，不对。这个人还藏着一截没说。 |
| 众人陷入了短暂的沉默之中。 | 屋里安静了。谁都没先开口。 |
| 这件事情给他带来了极大的心理压力。 | 这事压在他心里，吃饭都没什么味。 |
| 事情的发展完全超出了他的预料。 | 这跟他想的完全不是一回事。甚至还要离谱一点。 |

“甚至还要离谱一点”这种补说不是固定口癖。只有当叙述者需要停一下、吐槽一下或让听者确认重点时才使用。

## 轻微拖沓与自然冗余

| 过度压缩 | 适合听读的松一点写法 |
|---|---|
| 他拿钥匙开门进屋。 | 他摸出钥匙，把门打开，进去了。屋里没人。 |
| 她拒绝了他的请求。 | 她想都没想，直接摇头。“不行。” |
| 他发现手机没电，无法联系别人。 | 手机没电了。按了半天，还是黑的。想找个人问问，也没办法。 |
| 他很紧张，所以不断观察周围。 | 他站在门口，左看一眼，右看一眼。其实也没看出什么，可就是不敢进去。 |

自然冗余要服务动作顺序、听者跟进、人物态度或情绪停顿。不要把每个动作都拆开，也不要每句话都补一个“其实”。

## 允许的口语毛边

- 半句停住：“他本来想骂回去，话到嘴边，又算了。”
- 轻微重复：“跑了很久，真的跑了很久。”
- 自我补正：“那时候他还不知道。准确地说，是根本没往那方面想。”
- 搭配松一点：“这地方安静得不太对劲。”、“他心里多少有点发虚。”
- 叙述者插一句：“当然，这都是后话。”

这些毛边要让声音更像人在讲，不能牺牲事实、指代和基本可读性。

## 情绪外化范例

| 情绪 | AI 写法 | 人味写法 |
|------|---------|---------|
| 紧张 | 他感到一阵紧张，心跳不由自主地加快 | 他攥紧了手里的纸杯，水洒出来一些 |
| 愤怒 | 愤怒在他心中燃烧，他握紧了拳头 | 他把筷子往桌上一拍，碗里的汤溅了出来 |
| 悲伤 | 一丝悲伤涌上心头，她的眼中闪过泪光 | 她低头搅着咖啡，搅了很久 |
| 害怕 | 恐惧瞬间笼罩了他 | 他的背贴在墙上，不敢动 |
| 失望 | 她感到一丝失落，心仿佛被揪住 | “哦。”她把手机锁了屏 |
| 惊讶 | 他的瞳孔微微收缩 | 他张了张嘴，什么都没说出来 |

## 场景描写范例

- AI：`阳光透过窗帘的缝隙洒进来，在地板上投下斑驳的光影。空气中弥漫着淡淡的花香，仿佛整个世界都沉浸在一片宁静祥和的氛围中。`
- 人：`下午三点，客厅里只有钟在走。`

- AI：`天空阴沉沉的，乌云密布，仿佛随时都会下起倾盆大雨。凛冽的寒风呼啸而过，带着一丝刺骨的寒意。`
- 人：`要下雨了。风把晾在外面的衣服吹得乱晃。`

- AI：`他的拳头犹如疾风骤雨般猛烈，每一击都蕴含着不容置疑的力量。对手的瞳孔微微收缩，显然没有预料到如此凌厉的攻势。`
- 人：`他一拳怼过去，对方没躲开，嘴角破了。`

## 结尾改写范例

- 升华式：`他站在窗前，望着远方的天际线，终于明白了生活的真谛——有时候，放手才是最好的选择。` → `他把烟掐了，回屋睡觉。`
- 总结式：`这一刻，一切都变了。她知道，从今以后，她的人生将翻开崭新的一页。` → `她关上了那扇门。没回头。`
- 感慨式：`岁月如流水般悄然流逝……` → 直接删掉。

## 节奏调整范例

- 排比：`他看着她的眼睛，看着她的嘴唇，看着她微微颤动的睫毛，心中涌起一股难以名状的情感。` → `他看着她。她没说话。`
- 长句拆短：`当他终于推开那扇沉重的木门时，映入眼帘的是一间昏暗的房间，空气中弥漫着陈旧的气息，墙角堆满了落满灰尘的箱子。` → `门开了。屋里很暗，角落堆着几个箱子，上头全是灰。`
- 工整打碎：`她喜欢春天的花朵，喜欢夏天的阳光，喜欢秋天的落叶，喜欢冬天的白雪。每一个季节都有它独特的美。` → `她喜欢春天。别的季节也还行。`

## 对话改写范例

- AI 温和：`我觉得你这样做不太合适，能不能考虑一下我的感受？` → `“你眼里还有我吗？”`
- AI 完美解释：`其实我这样做是有原因的，因为当时的情况非常复杂……` → `“你能怎么着？”她把茶杯重重放下。`

### 对话情绪五级递进

1. 客观陈述：“你把我的东西扔了。”
2. 陈述+建议：“你把我的东西扔了，以后能不能先跟我说一声。”
3. 主观指责：“你凭什么动我的东西。”
4. 指责+命令：“你算什么东西，也配碰我的东西？滚出去。”
5. 指责+PUA：“我伺候你吃伺候你穿，你连个东西都放不好。你这辈子也就是这样了，离了我你什么都不是。”

### 震惊分层（人味写法）

- AI 一步到位：所有人都震惊了，不敢相信自己的耳朵。
- 人味分层：
  1. 对面的男人手抖了一下，茶杯里的水洒出来。
  2. 旁边的人互相看了一眼。有人往后退了一步。角落里有人开始掏手机。
  3. 刚才还趾高气扬的女人，脸上的笑僵住了。她张了张嘴，一个字没说出来。

## 重复复核提示

- 不设置固定字数的通用禁令。先判断整句或固定搭配是否在近距离无意重复；专名、术语、固定称呼和有意回环可以保留。
- 只换同义词通常不能解决重复问题：`他快速地跑` → `他迅速地跑` 可能仍然单调，应结合上下文删减、换观察角度或改变动作顺序。
- 例：`他一拳打在墙上，指节渗出血来，但他浑然不觉疼痛。` → `拳头砸上墙的时候他没感觉。低头才看见血从指缝里往下淌。`
