# 04 交稿验收

> 修改完成后、交付前最后把关。先跑检测评分（01），再做五维打分；两项都过才交付。

## 一、交稿前快速勾选

- [ ] 01 检测评分 ≥90 分
- [ ] 没有同一词语或固定模板在近距离异常重复
- [ ] 无「他终于明白 / 他不知道的是」章末体
- [ ] 无大段说明对白（说明书对白）
- [ ] 主要角色说话能听出差别（声线拉开）
- [ ] 情绪多靠动作/物件，少靠标签
- [ ] 句长有变化，无整页碎句装深刻
- [ ] 无密集的「一方面…另一方面」骑墙句
- [ ] 朗读像现代中文，不像翻译腔切碎
- [ ] 结尾弱钩子，不喊口号

## 二、五维打分（1-10，每维满分 10）

| 维度 | 问题 |
|------|------|
| 直接 | 在陈述还是在宣布/总结？ |
| 节奏 | 有呼吸还是节拍器？ |
| 信任 | 是否把读者当傻子解释？ |
| 像人 | 能否感到具体立场与代价？ |
| 密度 | 是否有可删的空句？ |

**总分 < 35/50 → 再改一轮。**

## 三、交付内容

- 改好的正文文件
- 检测报告（得分 / 预测 AIGC 区间 / 高危片段 / 修改意见 / 达标项）
- 五维打分结果
- 一句话说明：这轮动了哪类问题

## 四、校准闭环

- 用户真检测结果回填 `01-检测评分.md` 的映射表。
- 偏差 >0.1 时记录实际 AIGC 值，持续迭代校准。
