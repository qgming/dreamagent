# 04 交稿验收

> 验收同时看可测结构、口语化听读质量、人工质量和语义保真。没有任何一项能单独证明文本“像人”或“不是 AI”。

## 一、自动复核

- [ ] 修改后已重新运行 check_prose，failures 已清零
- [ ] warnings 已逐项解释或处理
- [ ] 叙述部分和对白部分都完成了目标口语化，没有只改引号内的说话
- [ ] 过密的书面连接、抽象名词串、四字格和复杂套句已按上下文复核
- [ ] 对话策略与章节功能一致；没有为了比例插入无功能对白
- [ ] 重复句、重复短语和固定搭配已判断是有意还是无意
- [ ] 数字、百分比、保护词和对白变化已人工核对

check_prose.pass=true 只表示当前规则没有硬性违规，不是质量分、作者认证或第三方 AIGC 分数。内置 5 篇样文只作参考，不作为所有作者的硬模板。

## 二、人工质量检查

每项 1-10 分，记录一句证据：

| 维度 | 检查问题 |
|---|---|
| 口语与听读 | 叙述是否像在讲故事？能否顺着读，是否有自然换气和落点？ |
| 声音 | 叙述者和主要角色是否有可辨认的立场与语言习惯，而不是被统一改成一种口语？ |
| 节奏 | 长短、停顿、自然冗余和信息释放是否服务场景，而非像固定节拍？ |
| 具体性 | 细节是否来自现场，是否减少了空泛总结？ |
| 保真 | 时间线、数字、专名、视角和对白意图是否保持？ |

总分只用于本次修改前后比较，不设置跨题材的硬阈值。任何一项低分都要回到具体句段，而不是整体重写。

## 三、交付内容

- 修改后的正文文件
- 复核报告：硬性违规、口语化与听读检查、重复与节奏风险、保真检查、修改意见、人工判断
- 一句话说明本轮实际修改了哪类问题

## 四、外部检测反馈

如用户提供第三方检测结果，只记录检测器名称、版本或日期、文本长度、分段方式和结果。不同检测器之间不能合并成一个“真实 AI 率”，也不能用一次结果反向要求文本破坏语义、听读流畅度或作者声音。
