# DreamAgent v0.1.4

v0.1.4 重点增强长篇创作中的文本分析、修改验收和目标驱动执行能力，并完成主进程服务的职责分层。Agent 现在可以在修改正文前后进行更细的结构分析和保真检查，也可以围绕一个明确的会话目标持续工作、验证结果并决定是否继续。

## 会话目标与自动执行

- 新增会话目标模式。用户可以在创作区为当前会话设置一个明确目标，目标与会话绑定，不会污染项目全局设定。
- 目标支持 `active`、`paused`、`blocked` 和 `complete` 四种状态，并保存目标说明、进度备注、状态原因、创建时间和更新时间。
- 目标会作为经过标记的本地项目数据进入系统上下文，Agent 能够把它作为本轮工作的验收标准，但不会把目标正文当作新的系统指令执行。
- 每轮 Agent 工作完成后，可以使用独立的目标审计 Harness 对项目快照进行检查。审计 Harness 不使用创作工具、不写入项目，也不会污染创作会话历史。
- 当审计确认目标尚未完成时，系统会记录进度、证据和下一步，并自动开始下一轮执行；当所有可验证条件满足时，目标会自动标记为完成。
- 审计返回格式无效、审计失败或证据不足时，系统会暂停自动续跑并将目标标记为阻塞，避免把计划或不完整结果误报为完成。
- 新增目标审计事件和状态恢复逻辑，创作区可以显示检查中、已继续、已完成和出错等阶段。

## 正文统计与写作分析

- 新增 `text_stats` Agent 工具，支持对项目文章 `chapters/{id}` 或直接传入的文本进行确定性统计。
- 基础统计覆盖原始长度、有效字数、行数、段落数、句子数、句末密度、段落长度分布、句长分布、对白比例、短段和长段比例等指标。
- 支持指定词语或短语进行计数，并返回命中行号、段落号、列号、偏移量和可选上下文；可同时统计各段落中的词语分布。
- 支持 `story-humanizer` 分析档案，输出结构分数、分段风险标记、对白期望和可解释的提示信息，用于辅助检查句式、段落和对白节奏。
- 支持传入作者认可的参考正文或项目内参考文章，生成参考样本基线、指标范围、距离和超出范围的提示；参考样本最多 20 篇，总长度最多 500000 字符。
- 统计结果包含正文哈希，后续编辑可以使用 `expectedSourceHash` 防止基于旧版本正文误修改。
- 文章读取支持按行范围读取，便于 Agent 只获取需要检查或修改的局部正文，减少无关上下文占用。

## 修改保真与文本对比

- `edit` 工具新增按行和按段落编辑模式。每次局部修改都要求提供 `expectedText`，在正文发生变化或目标内容不匹配时拒绝写入。
- 按行编辑保留原文换行风格，支持单行和连续多行替换；按段落编辑按空行划分段落，避免依赖脆弱的全文字符串匹配。
- `edit` 支持使用 `expectedSourceHash` 做整体版本保护，并限制 `edits`、`lineEdits`、`paragraphEdits` 同时使用，降低误操作风险。
- 新增 `text_compare` Agent 工具，对比修改前后的正文，报告字数和句子变化、数字增删、受保护词增删以及对白片段变化。
- 当数字、百分比、人物名、地点名或其他受保护词减少时，工具会生成保真警告；对白数量减少时提供复核提示。该结果用于辅助验收，不替代人工语义判断。
- 文章修改后仍会执行文章双链约束检查，章节正文不得写入不允许的双链内容。

## 网络搜索稳定性

- SearXNG 搜索实例改为每次请求打散候选顺序，避免长期固定使用同一公共实例。
- 自定义实例会去重并优先尝试；自定义实例失败后仍会回退到未重复的公共实例。
- 单次请求最多连续尝试 3 个实例，失败信息会明确说明尝试次数和最后错误，减少搜索请求长时间阻塞。

## 服务结构与维护性

- 主进程服务按职责拆分到独立目录：`agent`、`context`、`llm`、`mcp`、`network`、`project`、`session`、`skill`、`todo`、`update` 和 `utils`。
- Agent 编排、Harness、工具运行时和基础 Agent 工具集中在 `agent`；技能、待办、MCP 和网络工具分别归入对应业务目录，降低跨功能文件聚集。
- 项目库、图谱路径、活动台账和项目服务统一归入 `project`；会话服务、会话解析和旧版对话迁移统一归入 `session`。
- 更新主进程入口、IPC 注册器、服务内部引用和测试导入路径，保持现有运行时行为不变。
- 本次目录调整不改变项目文件格式、会话数据格式或用户配置路径，不需要额外的数据迁移。

## 技能与测试

- 持续完善 `story-humanizer` 的分析规则、参考资料和人类文风样本，使统计结果可以用于风格基线和交稿验收。
- 新增文本统计、文本对比、按行编辑、按段落编辑、参考正文校验和会话目标审计测试。
- 覆盖正文哈希过期、参考样本数量限制、工具参数校验、目标审计结果规范化和目标状态流转等回归场景。
- 发布前通过 Node/Web 两侧 TypeScript 类型检查，完整测试集共 8 个测试文件、52 个测试通过。

## 兼容性说明

- `text_stats`、`text_compare` 和会话目标属于新增能力，不影响已有项目资源和历史会话读取。
- 使用旧版 `edit` 的精确 `edits` 参数仍然可用；按行、按段落和哈希校验属于新增可选能力。
- 服务目录变化只影响源码导入路径，不影响打包后的用户数据目录、项目目录和配置文件位置。
