# DreamAgent v0.1.0

这是 DreamAgent（造梦师）的第一个对外发布版本。

DreamAgent 是一款面向小说、剧本和系列内容创作者的本地优先 AI 长篇创作工作台。它不把创作简化成一次性的聊天，而是围绕真实项目组织大纲、人物、世界观、正文、会话和 AI 工具，让创作者能够在同一个桌面应用中完成从灵感整理到成稿维护的完整流程。

v0.1.0 建立了 DreamAgent 的第一套公开产品基础：用节点规划故事，用实体维护设定，用文章承载最终正文，用双向链接组织内容关系，再让 AI 在明确的项目结构中读取资料、推进创作和修改内容。

## 首发亮点

- 发布 DreamAgent 桌面应用，提供 Windows、macOS 和 Linux 构建产物。
- 提供面向长篇创作的项目系统，统一管理节点、实体、文章、文件夹和创作会话。
- 提供项目内 AI 创作工作区，支持流式回复、上下文管理和结构化工具调用。
- 支持节点与实体的树状组织及双向链接，兼顾层级规划与关系追踪。
- 支持多个 OpenAI 兼容模型供应商、模型切换和思考等级配置。
- 内置长篇写作、短篇写作、文风优化、连续性审计等创作技能。
- 支持联网搜索和 MCP Server，为 AI 扩展外部信息与工具能力。
- 提供创作字数和 Token 消耗热力图，帮助回顾近期创作活动。
- 接入 GitHub Releases，可在应用内检查、下载并安装后续版本。

## 项目与创作资料

- 支持创建多个独立创作项目，每个项目拥有自己的标题、简介、节点、实体、文章和 AI 会话。
- 支持选择本地项目库目录，创作项目以本地文件形式保存，便于自行备份、迁移和管理。
- 支持在侧边栏展开项目并快速进入概览、节点、实体和创作工作区。
- 支持编辑项目名称和简介，项目列表会同步显示节点、实体和文章数量。
- 支持删除不再需要的项目，并在删除前进行明确确认。
- 支持最近项目列表，可直接回到项目最近一次创作会话。
- 支持读取和维护项目索引，使项目结构与磁盘中的真实内容保持一致。

## 节点：规划故事结构

节点用于保存主题、卷纲、章纲、场景、情节转折、创作任务和其他结构化想法。

- 支持创建、编辑、删除和重新排序节点。
- 支持多级父子结构，可用树状层级组织整部作品的大纲。
- 支持在不同父节点之间移动节点，并阻止形成循环结构。
- 支持 `idea`、`outline`、`draft`、`final` 四种状态，记录内容从想法到定稿的推进过程。
- 支持节点标题和详细内容，既可写简短定位，也可保存完整章纲。
- 删除父节点时保留其子节点，并将子节点提升到上一层，避免结构调整导致内容连带丢失。
- 支持从节点建立到其他节点或实体的引用，形成大纲与设定之间的关联网络。

## 实体：维护人物与世界观

实体用于保存人物、地点、势力、物件、规则、概念和其他长期设定。

- 支持创建、编辑、删除和重新排序实体。
- 支持多级父子结构，可按人物阵营、地点区域、设定类别等方式组织资料。
- 支持 `active`、`dormant`、`archived` 三种状态，区分当前使用、暂时搁置和归档设定。
- 支持实体名称、类型和详细内容，方便集中维护人物小传与世界观资料。
- 支持在不同父实体之间移动条目，并阻止循环挂载。
- 删除父实体时保留子实体，并自动提升其层级。
- 支持追踪实体被哪些节点或实体提及，减少长篇创作中的设定遗漏。

## 双向链接与关系追踪

- 节点和实体内容支持通过 `@` 提及建立结构化链接。
- 支持节点引用实体、节点引用节点，以及实体之间的相互引用。
- 正向引用会同步形成反向关系，可查看“当前内容提到了谁”和“哪些内容提到了当前对象”。
- 双向链接与父子树相互独立：父子关系负责层级，链接关系负责语义关联。
- 编辑内容时会重新解析有效引用，保证展示关系与实际文本一致。
- 删除目标内容后会清理失效引用，减少项目中残留的无效关系。

## 文章与文件夹

文章用于保存面向读者的最终正文，与承担规划职责的节点分开管理。

- 支持创建、编辑和删除文章。
- 支持 `draft`、`final` 两种文章状态，用于区分草稿和定稿。
- 支持多级文章文件夹，可按卷、篇章或其他出版结构整理正文。
- 文章文件夹对应真实磁盘目录，目录结构清晰且便于外部查看。
- 支持移动文章到不同文件夹，也可将文章移回项目根目录。
- 支持文章和文件夹排序，调整作品的实际阅读顺序。
- 支持记录文章来源节点及相关实体，让成稿能够追溯到章纲和设定。
- 删除文件夹时不会连带删除其中的文章和子文件夹，而是将内容提升到上一级。

## AI 创作工作区

- 每个项目支持多个独立创作会话，可在同一作品中分别处理大纲、人物、正文和审校任务。
- 支持模型流式输出，生成过程可实时显示。
- 支持打开历史会话、创建新会话、重命名会话和删除会话。
- 支持重新生成上一轮回复，便于比较不同写法。
- 支持中止正在进行的生成任务。
- 支持在 Agent 工作过程中追加引导或排入后续要求，让长任务能够持续推进。
- 支持显示模型、思考等级、上下文用量和消息耗时。
- 支持在会话中固定相关节点，为 AI 提供更明确的当前创作范围。
- 支持 Markdown、列表、引用、表格和代码块等常见内容展示。
- 工具调用过程与结果会在对话中单独呈现，便于了解 AI 对项目进行了哪些操作。

## 项目内置工具

AI 不仅可以回答问题，还可以通过受控工具直接参与项目维护。

- 读取项目概览、节点树、实体树、文章目录和具体内容。
- 创建节点、实体、文章和文章文件夹。
- 修改名称、正文、状态、父子关系、文件夹归属和引用关系。
- 删除项目内容，并遵循与界面一致的数据保护规则。
- 读取和更新创作待办，帮助拆解较长的写作任务。
- 在执行前读取项目中的真实 ID 和当前内容，减少凭空编造结构化引用。
- 工具运行在 Electron 主进程提供的受控边界内，渲染界面不会直接获得任意本地文件权限。

## 模型与思考配置

- 支持添加多个 OpenAI 兼容模型供应商。
- 每个供应商可单独配置名称、Base URL 和 API Key。
- 支持从供应商远程读取可用模型，也可维护自定义模型。
- 支持设置默认供应商和默认模型。
- 支持切换模型思考等级，为快速讨论和深度创作选择不同推理强度。
- API Key 由桌面主进程管理，不直接暴露给普通网页环境。
- 首次使用前需要在「设置 -> 模型」中完成至少一个可用模型配置。

## 联网搜索

- 支持为 AI 配置联网搜索能力，用于资料检索、背景调查和创作研究。
- 支持 Tavily、Exa、Serper、Brave 和 SearXNG 等搜索服务。
- 可分别配置搜索服务地址、凭据和相关请求参数。
- 搜索结果会作为 Agent 工具结果返回，可继续用于归纳、比较和创作。
- 联网搜索默认依赖用户自行选择和配置的第三方服务，其可用性与数据策略由对应服务提供方决定。

## 技能系统

- 内置面向长篇创作的写作流程，覆盖需求确认、框架设计、分段生成和质量检查。
- 内置短篇写作技能，适合更紧凑的结构、开篇和反转设计。
- 内置文风优化与去模板化技能，用于减少机械表达和重复句式。
- 内置 prose-craft 技能，用于细化叙述、对话、节奏和句面表现。
- 内置连续性审计技能，用于检查人物、时间、地点、物件和情节的一致性。
- 内置书名与简介技能，用于生成和评估标题、卖点与作品简介。
- 内置 DreamAgent 使用指南，帮助 AI 正确理解节点、实体、文章、双链和工具顺序。
- 支持启用或停用单个技能。
- 支持导入本地技能压缩包。
- 支持在应用内创建技能并维护 `SKILL.md` 与参考文件。
- 内置技能会随应用发布，并在首次启动或版本更新后同步到用户数据目录。

## MCP 扩展

- 集成 Model Context Protocol，可连接外部 MCP Server。
- 支持本地命令型服务和远程服务配置。
- 支持从 JSON 导入 MCP 配置。
- 支持发现服务提供的远程工具。
- 支持启用或停用整个 MCP Server。
- 支持按工具粒度控制是否向 Agent 开放，减少不必要的能力暴露。
- MCP 服务由用户主动配置，其权限范围和数据处理方式取决于对应服务实现。

## 首页与创作统计

- 首页提供最近项目列表，集中展示项目规模和最近活动。
- 提供最近 20 周的文字热力图。
- 分别统计节点、实体和文章的文字产出。
- 提供 Token 消耗热力图，帮助了解模型使用情况。
- 显示当天创作字数和 Token 用量概览。
- 支持从最近项目直接回到最后一次会话，减少重复导航。

## 桌面体验

- 提供基于 Electron 的桌面应用和无边框自定义标题栏。
- 支持窗口最小化、最大化、还原和关闭。
- 支持亮色、深色和跟随系统主题。
- 支持紧凑、清晰的项目侧边栏和设置中心。
- 外部网页链接使用系统默认浏览器打开。
- 开发环境支持热更新和调试工具，正式包加载本地构建资源。
- Electron 渲染进程启用上下文隔离，通过 preload 暴露受控 API。

## 本地优先与数据说明

- 项目资料、文章正文、创作结构和会话记录默认保存在本机。
- 用户可以自行选择项目库位置，并使用常规文件备份工具保护创作内容。
- 模型配置、技能配置和 MCP 配置保存在应用用户数据目录。
- DreamAgent 不提供内置云同步，跨设备使用时需要自行同步或迁移项目目录。
- 调用模型、联网搜索或 MCP 服务时，请求会发送到用户配置的第三方服务。
- 建议在长期创作过程中定期备份项目库，特别是在批量修改或删除内容之前。

## 发布与自动更新

- Windows x64 提供 NSIS 安装程序。
- macOS 提供 Apple Silicon 构建产物。
- Linux x64 提供 AppImage 和 deb 安装包。
- 安装包通过 GitHub Releases 统一分发。
- 应用启动后会定期检查新版本。
- 「设置 -> 关于」页面支持手动检查更新并显示当前状态。
- 发现新版本后可在应用内下载更新，并在下载完成后重启安装。
- 关于页面也提供 GitHub Releases 入口，可直接查看和手动下载公开版本。
- 发布流程同时生成 `latest.yml`、`latest-mac.yml`、`latest-linux.yml` 和 blockmap，供客户端识别和下载更新。

## 首发版本说明

- v0.1.0 是第一个公开版本，没有旧公开版本需要迁移。
- 首发安装包暂未配置商业代码签名，Windows SmartScreen 或 macOS Gatekeeper 可能在首次运行时显示来源提示。
- macOS 正式自动安装更新通常需要 Developer ID 签名与公证；未签名版本仍可通过 GitHub Releases 手动下载安装。
- Linux 桌面环境和发行版差异较大，如 AppImage 无法运行，可尝试 deb 安装包或从源码启动。
- 模型、联网搜索和 MCP 均依赖用户自行配置的服务，DreamAgent 不附带公共 API Key。
- 自动更新依赖能够访问 GitHub Releases；网络不可用时不会影响本地项目和编辑功能。
- 作为首个公开版本，跨平台兼容性、编辑体验和复杂长项目性能仍会继续完善。
