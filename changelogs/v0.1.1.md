# DreamAgent v0.1.1

v0.1.1 主要完善创作统计的持久化规则、应用内更新体验和 Agent 对项目基础信息的维护能力，同时统一侧边栏与下拉菜单的交互样式。

## 创作统计与数据持久化

- 首页文字与 Token 热力图数据现在按项目持久化到 `activity.json`，重启应用后仍会保留。
- Token 用量改为持续累加统计；删除当天或历史会话都不会减少已经产生的 Token 记录。
- 当天文字统计会随项目内容的增删实时变化，因此删除当天内容会同步减少当天字数。
- 日期进入下一天后，前一天的文字统计会冻结为历史记录；此后即使删除对应文件，历史字数也不会再变化。
- 旧项目会自动创建 `activity.json`，无需手动迁移。
- 升级前已经删除、且未被记录的历史内容与 Token 数据无法恢复。

## 自动更新与侧边栏

- 应用启动后会在后台自动检查新版本。
- 检测到更新时，会在侧边栏“设置”上方显示“立即更新”悬浮按钮。
- 点击更新后会在后台下载，下载完成时可选择立即重启安装，或暂不重启并在下次启动时安装。
- 软件名称右侧新增无 `v` 前缀的版本号胶囊，便于快速确认当前版本。
- 精简侧边栏品牌区域，移除名称左侧图标和下方英文副标题。

## 项目信息与 Agent 上下文

- 内置 Agent 工具现在可以读取项目名称与梗概。
- 支持通过 `write` 和 `edit` 工具修改项目名称与梗概；由 Agent 修改名称后，侧边栏会立即同步。
- 项目梗概会作为作品的主要介绍内容加入每次对话的系统提示词，帮助 Agent 持续理解项目背景与创作方向。
- 项目级工具调用支持以下形式：

  ```text
  read({ path: "project" })
  write({ path: "project", title?, summary? })
  edit({ path: "project", title?, edits? })
  ```

## 界面优化

- 统一应用内下拉菜单的选中样式，改为整行背景与阴影高亮。
- 移除选项左侧的黑色圆点，使下拉菜单与节点页面的选择体验保持一致。
