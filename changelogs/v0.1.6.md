# DreamAgent v0.1.6

发布日期：2026-08-06

v0.1.6 引入新的成稿检查工具与更完整的“人类写作”技能，并更新应用品牌图标。此次更新把面向通用中文创作的硬性禁令变成可直接调用的检查工具，让模型在交稿前能自查禁用的标点、黑话和句式；同时把此前偏统计的文本工具收敛为更聚焦的成稿校验，并补充了完整的写作技能参考材料。

## 成稿检查工具

- 新增 `check_prose` 工具，用于检查中文成稿中的硬性违规与模型化表达，只报警、不自动改文。
- 硬性违规覆盖中文/英文冒号、破折号、翻案句（“不是……而是……”等）、商业黑话（赋能、抓手、闭环、底层逻辑等）和“说白了、说穿了、先说结论”等硬性路标。
- 警告项覆盖语义化翻案句、名词化、上下文黑话、歌词式抒情词、模型路标、左分支句和密集“的”字结构，供作者自行判断。
- 检查结果返回是否可直接交稿（`pass`）、违规与警告明细（含行号）、汉字数以及各类问题计数，并支持传入正文或指定章节路径（`chapters/{id}`）。
- 新增 `hanCount` 汉字计数逻辑，检查报告中的字数统计更贴近中文正文的实际规模。
- 新增 FNV-1a 文本哈希工具（`text-hash`），供 `edit` 工具的 `expectedSourceHash` 做正文版本校验。
- 移除旧的 `text_stats`（含参考样本比较）与 `text_compare` 工具，原文本统计与比较逻辑不再作为独立工具暴露；相关测试同步迁移和清理。

## 故事人味化与人类写作技能

- 新增 `human-writing` 技能，覆盖知乎回答、论坛长帖、公众号文章、小说故事、对白、口播与演讲稿等通用中文创作与改稿场景。
- 技能把“活人感”拆成材料、说话位置和语气三层：非虚构稿先检查材料是否足以托住篇幅，虚构稿检查每个场景由人物目标、动作或变化托住，不用重复解释灌字数。
- 新增虚构、现实、论坛长帖、格式与改稿五份参考材料，分别提供人物声线、事实核验、长帖节奏、特殊形式和成稿禁令的细则。
- `story-humanizer` 技能更新到 1.4.0：通用成稿禁令与七遍改稿规则统一交给 `human-writing` 技能，本技能专注网络小说的口语化听读专项。
- 技能流程从“统计 → 基线比较 → 诊断 → 编辑 → 复核 → 验收”收敛为“自动检查 → 诊断 → 口语化编辑 → 验收”，复核报告改为硬性违规、口语化听读、重复节奏、作者基线偏离、保真检查与人工判断。
- 内置人类文风样文改为 `resources/skills/human-writing/references` 下的统一参考文件，供口语化阶段按题材和语气选择。

## 品牌与界面

- 更新品牌标志，替换为新图标，并移除旧的星形图标资源。
- 品牌 Logo 组件同步调整，不再引用已删除的星形图标。

## 兼容性与验证

- 老版本使用的 `text_stats`、`text_compare` 工具不再可用，相关技能已改为调用 `check_prose` 或直接参考 `human-writing` 技能规则。
- `human-writing` 与 `story-humanizer` 技能的交付禁令以 `check_prose` 可执行的硬规则为准，警告项不替作者决定文体。
- 新增 `check_prose` 单元测试，覆盖禁用的标点、黑话和句式检查；发布前通过 Node/Web TypeScript 类型检查与完整测试集。
