# DreamAgent v0.1.2

v0.1.2 重点修复“之前的对话没有作为上下文发送给 AI”的核心问题，并围绕长篇创作建立更可靠的上下文管理：历史、thinking 和工具调用链现在会完整进入模型请求；同时支持更多模型协议、旧版会话迁移和更稳定的会话读取。

## 上下文修复（重点）

- 修复历史对话丢失：此前当会话存在钉选节点、钉选实体或未完成待办时，模型请求会被替换为单条动态消息，导致之前的对话、本轮输入、thinking 和工具调用链全部消失。现已删除该替换逻辑，钉选与待办改为合入每轮重新生成的系统提示词数据分区，历史与工具链完整保留。
- 系统提示词升级为 V2：明确“系统规则 > 用户请求 > 项目资料 > 检索记忆”的权威顺序，并把项目资料、文章正文、网页内容标为数据而非指令，防止正文里的“忽略之前规则”等文本影响工具权限。
- 显式引用更可靠：在输入框中通过 @ 选择节点、实体、文章或技能时，会作为结构化引用传给主进程并重新读取资源，不再只当作文本。

## 模型与 Provider

- 支持按协议映射真实适配器：OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 各自使用对应实现，不再统一走兼容端点。
- 上下文百分比改为按最终请求估算（系统提示词 + 工具 + 当前输入 + 历史），更接近真实 Token 用量。

## 会话与数据

- 修复会话目录读取异常被误判为空并创建新会话的问题；同 ID 多文件按最新时间选择。
- 旧版对话（conversations）支持一次性迁移到新会话格式：自动备份、保留角色与正文、可重复执行、支持预演报告。
- 模型 / Provider / API Key 变更后自动失效旧缓存，避免继续使用过期配置。

## 体验与界面

- 新增应用内顶部通知提示（Toast），并在“关于”页检查更新后给出明确的成功提示。

## 稳定性与内部改进

- 引入自动化测试（npm test），覆盖历史完整性、工具链配对、模型协议适配等回归场景。
- 每轮编译复用项目快照缓存，图变更时显式失效，减少工具循环中的磁盘读取。
- 上下文构建引入预算与不变量校验：系统提示词版本/hash、当前用户消息、工具调用成对、预算不超窗口均在请求前检查。
- 按产品决策移除了面向用户的 Prompt 审计展示入口（该能力仅用于内部开发诊断，不向用户开放）。
