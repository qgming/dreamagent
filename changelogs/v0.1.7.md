# DreamAgent v0.1.7

发布日期：2026-08-07

v0.1.7 主要补齐多模态能力与模型默认值的一致性：主模型不支持图片时，可通过配置的视觉模型把图片转成文字描述后再转发；新对话的默认模型与思考强度改为以设置中的默认值为准；`write` 工具新增 folder 类型，可以直接创建文章文件夹；同时精简了 macOS 打包产物，仅构建 arm64。

## 多模态桥接

- 新增多模态桥接：主模型不支持图片输入时，后台用配置的视觉模型把图片转成结构化中文描述，再拼入用户文本转发给主模型。
- 桥接描述覆盖画面主体、场景、构图、色彩、风格、情绪与关键细节，图片中的文字会尽量完整 OCR 转写；多图按顺序分别描述。
- 设置面板新增「多模态桥接」下拉，仅列出支持图片输入的模型；未设置时保持原有行为。
- 主模型本身支持图片时原样放行，不经过桥接；桥接模型会自动校验仍存在且支持图片，失效时自动清空。
- 修复乐观用户消息：聊天中始终展示用户原始文本与原图，桥接文本只用于模型 prompt，不污染对话展示。
- 消息插话与排队消息同样走视觉桥接，行为与主对话一致。

## 默认模型与思考强度

- 新对话（无历史选择）时，默认模型始终以设置中的默认值为准，不再回落到第一个可用模型。
- 思考档优先使用设置里的默认思考强度，再按当前模型能力纠正；切换思考档时同步刷新顶部上下文展示。

## 创作工具

- `write` 工具 schema 新增 `type=folder`，可通过 `write({ type: "folder", name, parentId? })` 创建文章文件夹。
- `chapter` 支持传入 `folderId` 放入文件夹；工具描述同步更新。

## 打包与兼容性

- macOS 打包产物仅构建 arm64，与 leafagent 对齐，不再产出 x64 安装包。
- 设置存储新增多模态桥接字段，旧配置自动兼容，未配置时不影响原有多模态与图片附件行为。

## 验证

- 发布前通过 Node/Web TypeScript 类型检查与完整测试集。
