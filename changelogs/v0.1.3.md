# DreamAgent v0.1.3

v0.1.3 重点提升 Agent 回合的连续性、项目结构编辑能力和中文网文写作工作流，并同步更新品牌资源与创作界面细节。

## Agent 回合与上下文

- 新增正在运行回合查询接口 `agent:getRunning`。Agent 回合不再绑定发起请求的页面，主进程会向所有存活窗口广播流式事件；用户离开创作页、页面重新加载后返回时，可以恢复“运行中”状态，并继续使用取消、插话和追问控制。
- 模型输出上限改为使用模型目录提供的真实值，移除固定 32K 上限；上下文预算和自动压缩阈值会根据输入预算动态调整，减少因输入与输出同时逼近上下文窗口而被 Provider 拒绝的情况。
- 强化多步任务的待办约定：开始时建立完整清单，每完成一项或一批立即更新全量状态，任务结束后清空待办，避免 Agent 在工作未完成时提前结束回合。

## 项目结构与创作工作区

- `write` / `edit` 工具支持 `parentId`、`folderId`、`entityRefs` 和 `beatRefs`，可以移动节点或实体到指定父级或根目录，并直接维护 JSON 引用属性。
- 节点和实体更新统一支持重新挂载语义；仅修改 `parentId` 时会正常执行完整更新，不再被状态快捷更新逻辑吞掉。
- 创作区左侧待办改为可折叠分组，显示已完成数量；同时调整资料区、对话区和文章区的间距与文件夹操作按钮样式。
- 新增 `parentId` 编辑工具回归测试，覆盖移动到父级、移动到根目录以及与状态更新组合使用等场景。
- 移除文章列表行中的多余占位元素，减少不必要的渲染节点。

## 写作技能

- 新增并完善 `story-humanizer` 技能，提供检测评分、问题诊断、分层修改、交稿验收、禁词与句式、改写范例和人类文风基准的完整流程。
- 增加 5 篇人类文风样文，覆盖不同题材和叙事场景，用于建立改写语感与验收基准。
- 用 `story-humanizer` 替换原有 `deslop` 技能，清理旧技能引用、失效链接和不再需要的技能重写脚本。

## 品牌与界面

- 品牌图标从 SVG 切换为 PNG 资源，更新应用图标、浏览器图标、README 展示图和应用内品牌标记。
- 调整侧边栏品牌标记与文字的间距和尺寸，统一新的品牌资产使用方式。
